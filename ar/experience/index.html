Case Study 01

Modernizing a legacy WCF platform for AWS

The situation

A legacy WCF-based system had become increasingly difficult to change and maintain. The architecture was tightly coupled, deployments were difficult, and the platform faced performance, security and technology-lifecycle concerns.

My role

  • Assessed the WCF architecture and modernization risks.
  • Defined the AWS target architecture and migration stages.
  • Decomposed monolithic functionality.
  • Evaluated AWS Lambda versus ECS.
  • Designed identity and security considerations.
  • Led and guided implementation as the architecture evolved.

The result

The modernization enabled independently deployable components and progressive retirement of legacy WCF functionality, improving scalability, performance, resilience and observability while reducing coupling and maintenance effort.

Case Study 02

Architecture for a globally distributed enterprise system

The situation

A complex enterprise platform operates through multiple instances distributed across several continents while sharing a common codebase. The landscape includes desktop and web applications, monolithic and microservice backends, HTTP APIs, Kafka, WSO2 and external enterprise integrations.

My role

  • Overall integration architecture and Kafka-based communication.
  • API and WSO2 integration architecture.
  • Reducing architectural complexity and coupling.
  • Microservice decomposition and legacy modernization.
  • Communication between geographic instances.
  • Architecture principles, development patterns and technical leadership.

The result

The architecture evolved toward greater scalability and improved performance while reducing coupling between components. The changes improved maintainability, development workflows and the continued expansion of platform capabilities.
