Trade-offs

Synchronous or asynchronous?

Not everything needs to become an event. A well-designed distributed system usually combines multiple communication patterns.

The important decision is understanding where synchronous communication provides useful simplicity and where asynchronous communication provides resilience, scalability or decoupling.
